# dsh-yu-speak（主动说话）

没人跟她说话的时候，她自己决定要不要开口。

掷骰子在本地完成，**没掷中就一次模型调用都不花**。

---

## 它做什么

定时在本地掷一次骰子：
- 掷中 → 往某一间会话里送一条消息，让她走完整的一轮（人格、记忆、工具都在）。
- 没掷中 → 什么也不做，只记一条账。

**默认「试运行」是开的。** 装完先看它想说什么，觉得可以了再真的发。

---

## 安装

```powershell
dsh plugin --profile desktop add github:Speraymer/dsh-yu-speak
```

装完重启 DSH，设置里出现「主动说话」。

---

## 第一次使用

1. **勾会话**：设置页里勾上哪几间会话允许她主动开口（可以多选）。
2. **保持试运行**：默认开着，掷中了也只记账。
3. **看几轮记账**：设置页能看到每次的掷值、命中线和算式。
4. **满意了再关试运行**，并把「间隔分钟」调成你能接受的频率。

## 设置项

| 字段 | 默认 | 说明 |
|---|---|---|
| 总开关 | 开 | 关掉后这个插件彻底停摆 |
| 试运行 | **开** | 掷中了也只记账、不真发 |
| 目标会话 | 空（数组） | 勾了哪些；掷中一次只在一间里开口 |
| 间隔分钟 | `30` | 多久掷一次 |
| 开口频率 | `极少` | 三档：极少 20/60 · 适中 30/75 · 多一点 45/90（峰/谷命中线一起改） |
| 开口频率 | `极少` | 三档：极少 20/60 · 适中 30/75 · 多一点 45/90（峰/谷命中线一起改） |
| 安静起 / 安静止 | `1` / `8` | 安静时段（小时，含起不含止）；两者相等 = 不启用 |
| 触发文案 | `好久没人跟我说话了，我该主动去打个招呼` | 送进去的那句话 |

---

> ⚠️ 这 8 项已写死在代码里，设置页不再暴露：加成上限 40、近阈值 20 分钟、近因子 0.15、远阈值 360 分钟、远因子 1.5、没中加成 10、搭话冷却 20 分钟、角色恒为 `user`。想改只能改代码（`lib/host.js` 的 `写死`）。

## 运行机制

**一次掷骰**：取一个「现在」→ 判断是否在安静时段 → 判断峰时/谷时 → 算命中线 → 掷 0–100 → 比大小。

**命中线怎么来**：

```
线 = 基础线（峰 20 / 谷 60）
   × 近因子或远因子（按距上次说话的时间，二选一，都不满足就 1.0）
   + 没中加成 × 连续没中次数（封顶 40）
```

掷值 **小于** 线才算掷中。

**两个"多久"是两回事**：
- 「距她上次说话」——判断她是不是刚说完话（近因子）或沉默太久（远因子）。
- 「她自己上次开口」——判断冷却，防连续打扰。

**掷中之后**：先看一眼勾选的会话里哪些还活着、不忙；挑一间送一条消息。来源标记是 `speak-up`，不是冒充你亲手打的字。

**没掷中**：只记一条账，写着掷值、命中线和算式。设置页能一条条看。

## 边界与已知限制

- **只支持 `user` 角色**：填 `developer` 会被拒绝（会污染系统提示，不做）。
- **一次只挑一间会话**：不会同时往三个群里说话。
- **它不判断「对方是不是刚说过话」**：只用「距它上次说话」的时间。单人会话没问题；多人群里可能插话。
- **试运行默认开着**：想真发必须手动关掉。
- **频率调高就是持续烧额度**：每次命中都是一整轮。

---

## 依赖与降级

- 勾选的会话被归档或删掉时，这一轮跳过并记账（会写明「已归档」「没活着」「忙」）。
- 没有可用的会话时按设计**不自动唤醒**，这一轮什么都不做。
- 不依赖其他插件。
